# esh

esh translates English to shell. It should work as follows.

```bash
$ esh "list all files in the current directory with their sizes"
```

esh should contact an LLM to translate the English command to a shell command.

## First launch

When esh is launched for the first time, it should prompt the user to enter their Ollama server URL (default `http://localhost:11434`) and Ollama API key (default `None`). It should store them securely.

Once done, it should ask the user to select a model from the available ones.

## Maintaining history

esh should maintain a history of the commands it has translated. When I type `esh history`, it should display the list of translated commands.

If I type

```bash
$ esh "list all files in the current directory with their sizes"
```

and it is found in the history, then esh should use the command from history.

## Clearing particular history entries

When I type

```bash
$ esh --clear "list all files in the current directory with their sizes"
```

esh should remove the specified command from the history.
